# kylereis.github.io

Professional portfolio website for Kyle Reis — Healthcare IT, Analytics, and Security.

## About

This is a clean, lightweight personal website hosted on GitHub Pages. Built with semantic HTML5, plain CSS, and no external dependencies or frameworks.

**Focus**: Healthcare IT operations, data analytics, cybersecurity, and governance.

## Project Structure

```
├── index.html        # Main landing page
├── style.css         # All styling (dark mode, responsive)
├── README.md         # This file
└── assets/           # (future) images, icons
```

## Design Principles

- **Enterprise aesthetic**: Dark mode (navy/charcoal), professional typography, minimal visual clutter
- **Healthcare-oriented**: Teal/cyan accent color reflecting analytics and operational technology
- **Mobile-responsive**: Works cleanly on desktop, tablet, and mobile
- **Performance**: No frameworks, no external dependencies—pure HTML/CSS
- **Accessibility**: Semantic markup, proper heading hierarchy, readable contrast

## Sections

- **Header**: Name, professional tagline, and brief positioning statement
- **About**: Career background, expertise areas (operations, analytics, security, systems)
- **Current Focus**: Key interest areas (healthcare analytics, operational risk, data governance, security architecture)
- **Certifications**: CompTIA Security+, Cloud+, CASP+, and Bachelor's in Cybersecurity
- **Featured Projects**: PerDocMan, Health Data Analytics Portfolio, Security & Operations Writeups
- **Contact**: Links to GitHub, HerdSec, LinkedIn

## Development

To run locally or test:

```bash
# Serve on localhost:8000 (Python 3)
python -m http.server 8000

# Or with Node.js http-server
npx http-server
```

No build process required. All files are static.

## Deployment

Deployed automatically on GitHub Pages via main branch. Any changes to `index.html` or `style.css` are live within seconds.
